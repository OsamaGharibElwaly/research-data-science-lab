# Module 14: AWS Certified AI Practitioner — Practice Questions and Mock Exams

## 1. Purpose

This module provides original practice questions to reinforce the concepts covered in the AWS Certified AI Practitioner revision module.

These questions are study materials created for practice. They are not official AWS exam questions, and they do not reproduce confidential exam content.

## 2. How to Use This Module

1. Answer each question before checking the answer key.
2. Explain why the correct answer is appropriate.
3. Explain why the other options are less suitable.
4. Record missed concepts in `AIF_Weak_Areas_and_Revision_Log.md`.
5. Repeat incorrect questions after reviewing the relevant module.

Recommended practice cycle:

* Round 1: Untimed, focusing on understanding.
* Round 2: Timed, simulating exam conditions.
* Round 3: Review incorrect answers and weak topics.

Always check the current official exam guide for the exam format, scoring information, and objectives.

## 3. Practice Set A — AI and Machine Learning Fundamentals

### Question 1

A. Classification
B. Regression
C. Clustering

### Question 2

A. Underfitting
B. Overfitting
C. Data normalization
D. Reinforcement learning

Before attempting a full mock exam:

1. Review the latest official exam guide.
