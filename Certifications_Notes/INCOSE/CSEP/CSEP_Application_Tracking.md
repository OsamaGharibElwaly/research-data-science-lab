## 3. Application Checklist

### Phase A — Eligibility

* [ ] Review current CSEP eligibility requirements.
* [ ] Confirm which education route applies.
* [ ] Calculate qualifying professional systems engineering experience.
* [ ] Map experience to the required systems engineering experience areas.
* [ ] Confirm that the required number of months is supported by evidence.
* [ ] Identify experience gaps requiring further investigation.
* [ ] Confirm that claimed experience meets INCOSE's definition of qualifying experience.

**Eligibility notes:**

* Education route reviewed:
* Required experience under current rules:
* Experience that appears eligible:
* Experience requiring clarification:
* Official source and date checked:

### Phase B — Experience Documentation

* [ ] Create an entry for each relevant position or project.
* [ ] Record employment and project dates.
* [ ] Document personal responsibilities rather than only team achievements.
* [ ] Describe systems engineering activities performed.
* [ ] Identify relevant lifecycle phases and processes.
* [ ] Map each experience entry to applicable experience areas.
* [ ] Record supporting evidence and its location.
* [ ] Check for duplicate or overlapping time periods.
* [ ] Remove confidential or proprietary information from supporting descriptions.

### Phase C — References

* [ ] Identify potential references.
* [ ] Check each reference against current INCOSE criteria.
* [ ] Confirm that each person can verify the relevant experience.
* [ ] Discuss the application with potential references before entering them.
* [ ] Record contact details securely.
* [ ] Send each reference the relevant experience dates and descriptions.
* [ ] Track confirmation and follow up appropriately.
* [ ] Verify that all required reference coverage is satisfied.

See `CSEP_References_Status_Log.md`.

### Phase D — Application Submission

* [ ] Create or access the required INCOSE account.
* [ ] Complete the current official application.
* [ ] Enter education and professional experience accurately.
* [ ] Check all dates, job titles, and experience descriptions.
* [ ] Complete reference details according to official instructions.
* [ ] Review fees and payment instructions.
* [ ] Save a copy of the submitted application and confirmation.
* [ ] Record the submission date and application reference number.

### Phase E — Review and Examination

* [ ] Monitor application status and email.
* [ ] Respond to requests for clarification or additional evidence.
* [ ] Confirm eligibility approval and exam authorization.
* [ ] Verify the current exam format and candidate instructions.
* [ ] Prepare using the applicable Systems Engineering Handbook edition.
* [ ] Complete timed practice questions.
* [ ] Schedule the exam after reviewing readiness and available dates.
* [ ] Record the result and next steps.
