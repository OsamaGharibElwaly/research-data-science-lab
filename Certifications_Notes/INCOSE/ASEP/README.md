# INCOSE ASEP Certification Preparation

## Course Overview

**Certification:** Associate Systems Engineering Professional (ASEP)
**Organization:** International Council on Systems Engineering (INCOSE)
**Study format:** Markdown (`.md`) only
**Approach:** Theory + practical scenarios + exercises + exam-style questions + revision

## Learning Objectives

By the end of this course, you should be able to:

1. Explain the principles, terminology, and purpose of systems engineering.
2. Understand the system life cycle and the relationships between its stages.
3. Identify stakeholders, elicit needs, and develop measurable requirements.
4. Understand functional analysis, architecture, design, and trade studies.
5. Explain system integration, verification, validation, and transition.
6. Understand technical planning, risk management, configuration management, and decision management.
7. Apply systems engineering concepts to realistic engineering projects.
8. Review the key concepts needed for the INCOSE ASEP knowledge examination.

## Recommended Study Method

For each module:

1. Read the theory and learn the terminology.
2. Study the worked example.
3. Answer the exercises without looking at the solutions.
4. Complete the multiple-choice questions.
5. Review incorrect answers and record the underlying concept.
6. Revisit difficult topics during weekly revision.
